## 템플릿 공통 가이드

### 위젯 배치
- 페이지 상단에 눈에 띄게 배치 (첫 인상이 핵심)
- /embed → widgets.doriri.dev URL 붙여넣기

### 테마 통일
- 위젯 테마를 템플릿 톤에 맞출 것
- 밝은 템플릿 → soft 테마 / 어두운 템플릿 → minimal 테마

### 커스텀 안내
- 템플릿 안에 "위젯 커스터마이즈하기 →" 링크 포함
- 링크: https://widgets.doriri.dev/ko/widgets/

### 언어
- 영문 우선 등록 (글로벌 시장이 10배+)
- 한국어는 별도 템플릿으로 등록

### 스크린샷
- 3~5장 준비
- 다크/라이트 모드 둘 다 보여주기
- 첫 장은 전체 뷰, 나머지는 섹션별 클로즈업

### 설명문 필수 포함
- "Includes live embedded widgets from doriri"
- widgets.doriri.dev 링크
